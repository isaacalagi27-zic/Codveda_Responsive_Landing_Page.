NOVA Studio — Responsive Landing Page

NOVA Studio is a modern, responsive landing page for a digital creative studio. The website showcases digital services, introduces the studio, and encourages potential clients to get in touch about their projects.

This project was developed as Task 1: Responsive Landing Page for the Codveda Technology internship.

 Features

 Responsive Design: Adapts to desktop, tablet, and mobile screens.

Modern UI: Dark theme with deep-purple accents and a clean layout.

Navigation Menu: Includes a mobile-friendly hamburger menu.

Services Section: Showcases the studio's digital services.

About Section: Introduces the studio and its goals.

Contact Section: Includes a call-to-action button that opens an email application.

Scroll Animations: Elements appear smoothly as visitors scroll through the page.

Smooth Navigation: Navigation links take visitors to the relevant page sections.

Dynamic Footer Year: JavaScript automatically displays the current year.

Accessibility Considerations: Includes navigation labels, keyboard support, and reduced-motion preferences.


Technologies Used

HTML5 — semantic page structure

CSS3 — styling, Flexbox, Grid, responsive layouts, and animations

JavaScript (ES6+) — menu interactions, scroll effects, and dynamic content
